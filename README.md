# Linux Wargame Write-ups (OverTheWire: Bandit)

## Overview
This repository contains my personal notes, scripts, and command-line strategies developed while progressing through the [OverTheWire: Bandit](https://overthewire.org/wargames/bandit/) wargame. 

I am using this challenge as an active "Infrastructure Lab" to build deep, practical muscle memory in Linux systems administration, which serves as the foundation for my upcoming work in Docker, CI/CD, and Cloud Infrastructure.

## Core Skills & Concepts Covered
Through these challenges, I am actively practicing and documenting:
* **CLI Navigation & File Systems:** Advanced directory traversal, hidden files, and file types.
* **Security & Permissions:** Managing SSH keys, understanding user/group permissions, and `chmod`/`chown`.
* **Text Processing & Piping:** Utilizing `grep`, `awk`, `sed`, `sort`, `uniq`, and `tar` to manipulate data streams.
* **Networking Fundamentals:** Establishing raw connections via `nc` (netcat), working with localhost, and understanding ports.
* **Bash Scripting:** Automating repetitive command-line tasks and writing basic shell scripts.

## Repository Structure
The notes are organized by level brackets. Each file contains the objective, the commands used to solve the problem, and a brief explanation of the underlying Linux concept learned.

* `Level_00_to_05.md` - Basics, SSH, and file reading.
* `Level_06_to_10.md` - File searching, permissions, and string extraction.
* `Level_11_to_15.md` - Hex dumps, compression (`tar`/`gzip`), and SSH key management.
* `Level_16_to_20.md` - Port scanning, netcat, and SSL connections. (Currently Here)
